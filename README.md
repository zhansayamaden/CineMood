# CineMood 🎬

## Жоба туралы
CineMood — пайдаланушыларға өз көңіл күйіне сәйкес фильмдерді табуға, бағалауға және жеке коллекциясына сақтауға мүмкіндік беретін веб-платформа.

## Жобаның мақсаты
PHP және MySQL технологияларын пайдаланып, фильмдерді іздеу және басқару жүйесін әзірлеу.

## Қолданылатын технологиялар
- HTML5
- CSS3
- JavaScript
- PHP
- MySQL

## Негізгі функциялар
- Тіркелу және жүйеге кіру
- Фильмдер каталогын қарау
- Фильмдерді іздеу және сүзу
- Көңіл күй бойынша фильм таңдау
- Таңдаулы фильмдер тізімін жасау
- Баға беру және пікір қалдыру
- Әкімші арқылы фильмдерді басқару

## Дерекқор
Дерекқор атауы: `cinemood_db`

- `users` — пайдаланушылар
- `movies` — фильмдер
- `moods` — көңіл күй санаттары
- `favorites` — таңдаулы фильмдер
- `reviews` — пікірлер мен бағалар

## Жобаның кезеңі
8-апта: Жобаны жоспарлау және репозиторийді дайындау.



# CineMood — Movie Recommendation Platform

CineMood — пайдаланушының көңіл күйіне сәйкес фильмдерді
іздеуге және таңдауға арналған веб-платформа.

## Жобаның мақсаты

Пайдаланушыға өзінің көңіл күйі мен қызығушылығына
сәйкес фильмдерді ыңғайлы түрде табуға мүмкіндік беретін
веб-қосымша әзірлеу.

## Негізгі мүмкіндіктер

- Пайдаланушыны тіркеу және жүйеге кіру
- Фильмдер каталогын көрсету
- Фильмдерді атауы мен жанры бойынша іздеу
- Көңіл күй бойынша фильмдерді сүзгілеу
- Фильм туралы толық ақпаратты көрсету
- Таңдаулылар тізімін қалыптастыру
- Фильмдерге баға беру және пікір қалдыру
- Әкімші арқылы фильмдерді қосу, өзгерту және жою

## Қолданылатын технологиялар

- HTML
- CSS
- JavaScript
- PHP
- MySQL
- XAMPP
- GitHub

## Дерекқор

Дерекқор атауы: cinemood_db

Негізгі кестелер:

1. users — пайдаланушылар
2. movies — фильмдер
3. moods — көңіл күйлері
4. favorites — таңдаулы фильмдер
5. reviews — пікірлер мен бағалар

## Жоспарланған веб-беттер

- index.php — басты бет
- register.php — тіркелу
- login.php — жүйеге кіру
- movies.php — фильмдер каталогы
- movie.php — фильм туралы толық ақпарат
- profile.php — пайдаланушы профилі
- admin.php — әкімші панелі
